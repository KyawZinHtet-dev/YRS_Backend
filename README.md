About The Project
The Yangon Railway System (YRS) Backend is a web-based application built to address the difficulty of navigating train routes and schedules in Yangon. This project serves as the core backend infrastructure, providing both a comprehensive management system for administrators and functional APIs for frontend applications.
​Key Features:
​Admin Dashboard: A modern, single-page application (SPA) dashboard built with Laravel, Inertia.js, and React. Styled with Shadcn UI for a clean, accessible, and highly responsive user experience.
​Route & Station Management: Allows administrators to easily create, update, and manage train stations, transit routes, and schedules.
​API Endpoints: A fully functional RESTful API designed to deliver structured data (routes, stations, timings) to client-facing frontend portals or mobile applications.
