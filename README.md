# 🚆 Yangon Railway System (YRS) - Backend & Admin Portal

A backend architecture and administrative dashboard designed to simplify train and route discovery across Yangon. This project serves as the core infrastructure for the Yangon Railway System, providing a robust management interface for administrators and fully functional APIs for frontend client portals.

## ✨ Features

- **Admin Dashboard:** A modern, single-page application (SPA) dashboard for administrators to manage the railway system efficiently.
- **Route & Station Management:** Complete CRUD (Create, Read, Update, Delete) operations for managing train stations and transit routes.
- **RESTful APIs:** Scalable and well-structured API endpoints designed to serve data (routes, stations, schedules) to client-facing frontend portals or mobile applications.
- **Seamless SPA Experience:** Built with Inertia.js to connect Laravel and React without building a separate API for the admin panel, providing a blazing-fast user experience.
- **Modern UI:** Styled using Tailwind CSS and Shadcn UI for a clean, accessible, and highly responsive interface.

## 🛠️ Tech Stack

**Backend:**
- [Laravel](https://laravel.com/) - PHP Framework
- RESTful API Architecture
- MySQL (Database)

**Frontend (Admin Dashboard):**
- [React](https://reactjs.org/) - JavaScript Library
- [Inertia.js](https://inertiajs.com/) - Monolith SPA Router
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [Shadcn UI](https://ui.shadcn.com/) - Reusable UI components
